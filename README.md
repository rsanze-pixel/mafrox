# MAFROX · mafrox.com.pe

Web estática (HTML, CSS y JS). Cada cambio que se sube a la rama `main`
se publica solo en el hosting (ver `.github/workflows/publicar.yml`).

- Imágenes y videos: carpeta `images/` (mismo nombre = se reemplaza sin tocar código).
- Textos: dentro de cada `.html` (atributos `data-es` / `data-en`).
